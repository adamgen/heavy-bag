# Name Check: "Heavy Bag"

_Get a full clearance search from a trademark attorney before committing to
any name._

## Limits of this research

lookup service: USPTO, EUIPO, UKIPO, WIPO, RDAP, WHOIS and DNS. **Only web
search worked.** So:

- Trademark findings come from third-party aggregator snippets (Justia,
  Markinton, TrademarkElite, UK IPO journal pages). They were **not verified**
  against the registries.
- **No domain or social handle was verified.** The tables below are

### Risk

- **Conflict with existing marks: low to moderate.** The only same-name
  class 18 mark appears dead. Still check for unregistered use on bags.
- **Too descriptive to protect: HIGH — the real problem.**
  - Class 28: "heavy bag" is the generic name for a punching bag, so it
    can't be registered for fitness goods.
  - Class 18: for a bag whose selling point is being heavy, "HEAVY BAG"
    describes the product, and is likely to be refused as merely
    descriptive. At best we'd get weak protection (US Supplemental Register,
    or a logo with the words disclaimed). We probably couldn't stop
    competitors from using the term.
- **Search and SEO: very poor.** Results for "heavy bag" are all boxing
  equipment.

## 4. Recommendation

**Don't use "Heavy Bag" as the main brand.** It's weak to protect
(descriptive for our bags, generic for fitness goods), buried by boxing
search results, and the .com is probably taken. It still works as a product
or line name under a distinctive brand (e.g. "COUNTERWEIGHT Heavy Bag 01"),
or in a tagline.
